# Privacy Policy

**App:** Home Climate Controller
**Last updated:** November 11, 2026

Home Climate Controller ("the app") is a private home automation app used by a single household to control its own thermostat and window shades. This policy explains what data the app accesses, how it is used, where it is stored, and how access can be removed.

## Who uses the app

The app is used only by the members of the household that runs it. It is not available to the public, and no one outside the household can sign in to it or see its data.

## Google user data the app accesses

With the account owner's permission, the app uses the Google Nest Smart Device Management API (scope `https://www.googleapis.com/auth/sdm.service`) to access the household's own Google Nest devices. Specifically, it reads and controls:

- Thermostat: current temperature, humidity, heating/cooling mode, set temperatures, heating/cooling status and fan status.
- Nest temperature sensors: temperature readings.
- Device names and the rooms they are assigned to.

The app does not access Gmail, Google Drive, Contacts, Calendar, location history, camera video or any other Google account data.

## How the data is used

The data is used only to provide the app's features for the household:

- running the household's thermostat schedule;
- adjusting the set temperature so occupied rooms reach the chosen temperature;
- running the system fan to even out room temperatures;
- pausing heating or cooling while an exterior door is open;
- showing current temperatures and status on the household's private home dashboard.

The data is not used for advertising, profiling, analytics, machine-learning training, or any purpose unrelated to these features.

## How the data is stored and protected

- Device readings are stored only on the household's own home server, on a private home network. They are kept as ordinary history (for example, past temperatures) for up to 30 days, or longer only if the household chooses.
- The Google sign-in token is stored only on that same home server, which is password-protected.
- Data is sent to and from Google over encrypted (HTTPS) connections.
- The app does not store data on any other server or cloud service.

## Sharing

The app does not sell, rent, transfer or disclose Google user data to anyone. It shares no data with third parties. The only exchange of data is between the household's home server and Google, as needed to read and control the household's own devices.

## Google API Services User Data Policy

The app's use and transfer of information received from Google APIs adheres to the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements.

## Removing access and deleting data

- Access can be revoked at any time at [myaccount.google.com/permissions](https://myaccount.google.com/permissions) by removing "Home Climate Controller", or by removing the app from the Nest permissions in the Google Home app.
- Once access is revoked, the app can no longer read or control any Google Nest device.
- Stored history can be deleted from the home server at any time by the household.

## Children

The app is not directed to children and does not knowingly collect data about children.
